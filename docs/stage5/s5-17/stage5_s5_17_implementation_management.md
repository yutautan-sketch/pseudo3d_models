## 4. 評価器と比較仕様

### 4.1 構成と座標

`Stage5/stage5/geometry/`にtypes、transform、frame_geometry、fl_estimate、postprocess、matching、prior、metricsを置く。
幾何コアはnumpyのみ、torch・h5py非依存。I/O・契約検査は`evaluate_stage5_geometry.py/.sh`へ分離する。
既存学習・評価コード、pins、Stage2to4は変更しない。

座標はLOCAL_CROP_PX、RAW_FRAME_PX、RAW_FRAME_NORM、MM_XY、PSEUDO3Dを区別する。
基本計算はRAW_FRAME_PX。mm確定後の異方変換ではMM_XYでPCAを再計算する。
Zの物理mmは未確定であり、pseudo-3D長をmmと呼ばない。
`InstanceGeometry`は重心centroidと矩形中心centerを区別し、存在・失敗理由・使用frame・単位を出力に保持する。
端点交換・軸符号に不変な誤差を使い、選択scoreを正解確率と呼ばない。
M3のmatchingは重心間距離で行う。報告する中心誤差は矩形中心centerの誤差であり、matching用の重心間距離と指標名・説明で区別する。

### 4.2 表現・後処理

| 表現 | 定義・動画集約 |
| --- | --- |
| (a) | frame AABB長辺、動画q90。長辺>0なら成立し、面積0の水平・垂直線分も長さを持つ。全点同一（長辺0）は未定義 |
| (b) | PCA主／副軸の2〜98分位矩形、主軸長の動画q90 |
| (c) | (b)の中心線の両端点、長さの動画q90 |
| (d) | (c)の長さを1frameで取る。選択はGT表現＝GT点数（保持評価は構築側Aの点数のみ）、実用＝予測情報（点数×平均確率）、oracle＝GT選択frameを予測に適用し別表。3者は別関数。score同値は最小frame_order、crop端2 pixel以内に触れるframeは選択不可 |
| (e) | pseudo-3D軸の参考値。候補選定から除外 |

(b)(c)は主軸範囲`[t02,t98]`、副軸範囲`[s02,s98]`を共有する。
端点は`(t02,s_mid)`と`(t98,s_mid)`、矩形中心は`(t_mid,s_mid)`。
幅は`s98-s02`。両者の領域と長さは一致し、被覆率で優劣をつけない。

後処理はP0なし、P1最大成分、P2frame持続性、P3確率上位K、P1+P2の5種。
P1は距離4 local pixel、最小5点。P2は前後2frame、train_coreで長さが定義できるM1 frameの(b)長さ中央値の0.5倍以内の中心距離（長さ未定義のframe数を記録）。
P3のKはtrain_coreの陽性frame（有効GT陽性点が1点以上あるframe。最小5点のinstance成立条件とは別）あたりの有効GT陽性点数の中央値。これらの定数をvalidationで調整しない。
P3は保存済み`pred_label`に陽性点が1点以上あるframeだけを対象とし、そのframe内で確率上位K点（0.5未満を含む）を選ぶ。目的は陽性候補frame内の点選択の比較である。予測陽性のないframeのFNはP3で回復できないこと、P3の対象frameと後処理後に最小5点の成分が成立する幾何的な存在frameは別であることを結果に付記する。
最大3表現×5後処理×best/lastの最大30組。最良後処理の選択はbestで行い、validationによる開発選択と明記する。
H17-2の表現はH17-1の主・副候補とする。H17-1で候補が決まらない場合（判断保留を含む）に限り、**(a) AABB、(c) PCA中心線端点、(d) best-frame端点の3表現**を計算する（(b)は(c)と長さ・領域が共通のため除く）。この3表現はコードで固定し、出力で「診断対象であり採用候補ではない」と示す。実データの結果を見て入れ替えない。この固定はS17-5の実施承認ではない。
GT／予測の最大instance M1、全instance統合M2、ゲート付きmatching M3を分ける。

### 4.3 保持被覆率と摂動

被覆率`C_ho`は**記述量であり足切りに使わない**。面積はraw px²に統一し、GT点をマスク面積と扱わない。
箱の相対膨張率は同一instanceの凸包面積に対する記述量とし、退化は未定義とする。
面積に基づく量（保持被覆率の(a)、相対膨張率）はAABB面積0を未定義（`zero_area_aabb`）とし、長さ推定の成立条件とは分ける。

保持評価は分割前にM1を固定し、n≥10をA=ceil(n/2)、B=floor(n/2)へseed0/1/2で分割する。
Aのみで構築・(d)のframe選択を行い、Bで被覆を測る。A/Bとも5点以上。
軸曖昧（λ2/λ1>0.9）、共線・幅0等の退化を区別して記録する。
主比較は全表現で成立する共通frame集合、seedごとに3frame以上の動画を対象とする。
(a)〜(c)はframe→動画中央値、(d)は選択frameの値。動画ごとに3seedの中央値、その後動画間を集計する。
seed不足の成立条件は合成テスト報告で明記し、都合のよいseedだけで集計しない。

摂動は各3seed、間引き50%・75%、背景FP10%・30%、local座標σ1 pixelの揺らぎの**計15通り**。
間引きは非復元で最小min(n,5)を保持。FPは有効背景点から非復元抽出し、GT・ignoreを含めない。
要求数・実数・不足frame数を報告する。揺らぎは切り詰めず、元データへの範囲検査と区別する。
5区分ごとに動画の相対変化を3seed中央値へまとめ、動画間中央値・P90を出す。

### 4.4 候補選定と指標

候補選定は各摂動区分で相対変化率中央値≤5%、P90≤15%という事前規約を用いる。
臨床的基準ではない。**失敗例の扱いは5章に従い、実データ前に確定する。**
主候補は5区分のP90最大値が最小の表現。差が1パーセントポイント以内なら(c)→(d)→(b)→(a)。
副候補は最大2。候補なし・選定不能は管理へ返し、基準を緩めて再実行しない。

validationの相対誤差10%以内の件数・過半、prior比+3件、FP遠方割合、M1/M2差は記述的比較だけに使う。
BBoxと点GTの整合性（H17-1b）は、全BBoxを包む領域と全GT instanceを包む領域の比較による記述量であり、個々のinstance対応の精度とは区別する。
候補除外や臨床的な成功判定へ自動適用しない。
priorはtrain_coreのGTだけから構築する。各frameのM1点を元frame正規化座標`(x/W, y/H)`へ写して箱を当て直し、中心・軸角度（2倍角平均）・長さ（動画q90）・幅（中央値）を**すべて正規化空間**で持つ。対象動画へはその`(W, H)`で箱の中心・端点・角を写像し、元frame pixelの長さ・角度・幅・AABBを写像後の点から導く。正規化長は等方でなく、解像度・視野の異なる動画を正規化空間で平均する限界を明記する。存在はtrain_coreの正規化時刻10区間の存在率>0.5。prior-onlyの(d)は最初の存在frame、存在frameがなければ失敗。
in-sampleでは対象identityを除く。同一検査の兄弟ファイルが残る限界は明記する。
frame存在TP/FP/FN/TNとinstance matchingのTP/FP/FNは別指標。
FPの距離区分は有効背景上のFPを分母とし、ignore割合・全有効予測陽性を分母とする値とは分ける。
遠方FPを別の解剖構造と断定しない。

最終的な方式選択はS5-20a/bまでの開発側で完結させる。
internal_test・外部testは選定済み構成の評価用であり、結果を見て選び直さない。

### 4.5 S17-5結果の解釈（確定事項）

- **撮像条件（ユーザー説明）:** 断面は動画によって異なり、基本は横断像（点・楕円状）か斜めの断面像（線状）。sweepは一定方向に進み、大腿骨の一端から他端までを覆う。sweepの方向と骨の伸びる方向には直接の関係がない。pseudo-3Dの曲がりにはStage 2（dualtrack）の精度の影響がある。個別動画の断面分類やdualtrackの誤差量は測定していない。
- **(a)〜(d)** は「元frame平面内のGT陽性領域に由来する2Dの広がり・長さ」、主に**各frameに映る骨断面の2Dの広がり**と呼ぶ。臨床FLや骨の解剖学的全長と同一視しない。約30.9 raw pxという絶対値だけで断面の種類を判定しない。
- **H17-1** は、事前に定めた摂動・判定規則に対するGT由来幾何量の安定性試験として成立した。正式な選定記録は**主(c)・副(b)(d)**のまま保持する。主(c)はこの量の表現としての安定性を示すにとどまり、FLに必要な情報の保持を証明したとはしない。
- **(b)と(c)** は長さ・領域が同じ表現群であり、独立した2方式の支持とは数えない。(c)を代表とし、(b)は同じ幾何をboxで表す補助形式、(d)はframe選択を含む別の構成と説明する。(a)はH17-1に合格したが選定上限により候補外となった記録として保持し、追加の予測評価対象にしない。(b)を(a)へ差し替えず、H17-2の対象も遡及変更しない。
- **(d)の「最良frame」** は骨全長の測定断面を含むことを意味しない。S5-16の「臨床手技に相当」という説明は今回の動画一般の前提として引き継がない。複数frameで骨全体を観測することと、frameの進行方向が骨の長軸に一致することは別である。
- **H17-2〜H17-4** は、bestの存在recallが高い一方でGTの無いframeへの予測が多く、GT由来長さとの一致も限定的だったと整理する。(d)+P3の10%以内6/18はvalidation上で選んだ開発上の記述結果であり、後処理の一般的優位性・臨床FL精度・production採用を示さない。lastで長さ誤差が小さくなる部分は、存在recallの低下とoracleの定義件数の減少と併記し、単独で改善と結論しない。
- **FP摂動** は「同一frameの有効背景から一様に点を加える事前固定の摂動に対して変化が小さかった」という限定した頑健性として記載する。孤立点が最小成分条件で除かれた、またはM1へ影響しなかったという説明は推論として表示する。まとまった領域・時間的に連続する誤検出・別instanceが最大成分になる場合への頑健性は示していない。H17-1の合否は変更せず、FP摂動の差し替え・追加試験はしない（必要なら後続段階の事前計画として提案する）。
- **(e) pseudo-3D** は単位制約付きの参考値・候補外のまま集計する。sweep距離、frame数、重心軌跡長をそのまま骨長とせず、frame間の位置・姿勢と物理スケールの対応を必要とする。dualtrack由来の形状歪みは後続の長さ推定に影響し得る上流工程の限界として明記し、曲がりを解剖学的形状とも追跡誤差とも断定しない。今回の結果への補正・再計算、Stage 2の変更、追加の実データ検証はしない。
- **S5-20への引継ぎ** では、(1) 確定した2D断面由来量の安定性とGT・予測間の一致／不一致、(2) 撮像条件（動画ごとに異なる断面、骨全体を覆うsweep、sweepと骨長軸が直接対応しないこと）、(3) pseudo-3Dの単位・物理幾何との対応、dualtrack由来の形状歪み、FL推定に許容する誤差が未確定であること、を分けて記載する。

## 5. 失敗・未定義・実行条件（必須補足を含む）

### 5.1 安定性選定と失敗

**成功例だけの中央値・P90で候補を合格させない。** 通過条件は方式F-Aとする。
- 手法側の失敗（GT基準長が未定義、摂動後の長さが未定義、3seedのいずれかが未定義）は、その動画・摂動区分を**最悪値**として扱い、分母に残す。入力評価不能は分母から除く。
- 選定用の中央値・P90は、補間しない最近順位法（1始まりの順位`ceil(q·n)`の値）で求める。P90が最悪になるのは、最悪扱いの動画数が`n − ceil(0.9n)`を超えるとき。
- 最悪値は判定上の扱いにとどめ、出力にInfinity・NaNを書かない。値は`null`とし、最悪かどうかのフラグと最悪扱いの件数を別項目で示す。
- 各区分の選定用中央値≤5%かつP90≤15%で合格。失敗を最悪値として分母に含め、選定用中央値またはP90が最悪値となるか、対応する閾値を超えた場合に、その区分を不合格とする（失敗が1件でもあれば直ちに不合格という意味ではない）。**全動画が全区分で未定義なら「選定不能」**とし、不合格と区別する。
- 記述用の成功例だけの統計と、失敗を含む選定用統計を分けて出力する。
- 選定不能・不合格の表現は候補から外し、残る合格表現から主・副候補を選ぶ。除外した表現と理由を記録する。入力件数不足などによる全体の保留は、この処理で回避しない（保留中は規則の結果を記録のみとし、候補として使わない）。
- 合格表現がなければ、全表現が選定不能なら「選定不能」、それ以外は「候補なし」として管理へ返す。

入力側の変換不能と手法側の失敗を区別する。予測なし・幾何なし・点不足・退化は手法側の失敗として
評価可能件数に残す。全18件＝入力評価不能＋評価可能、評価可能＝成功＋手法失敗として報告する。
数値統計は成功件数とともに、失敗率は評価可能件数を分母として併記する。
幾何コアの`empty`はCLIがGT／予測の文脈で分類し、予測では元から予測陽性がない場合と後処理で消えた場合を区別する。
入力側でtrain_core130件未満、validation16件未満、またはtrain_coreの10%以上のモードが全件除外なら
全体としての判断を保留する。手法失敗を入力評価不能へ移してこの条件を回避しない。
相対量のL=0・分母0・誤差対象なしはnullと件数で示す。分母が正でTP=0ならprecision/recallは0である。

### 5.2 合成被覆率の解釈

**92〜96%という範囲は有限標本の保持側被覆率の保証ではない。** 理想化した分布の説明と、
有限標本・推定PCA・保持側評価を分ける。解析値と違うだけで実装不良としない。
既知座標・形状の厳密検査と、seed固定の確率的な被覆率観測を分離する。
矩形、長短比5:1のガウス楕円、曲がった帯、2領域について20/100/1000点を調べる。

### 5.3 coverageと過去hash

**今回必須のcoverageが欠落した場合は停止する。登録後のhash不一致も停止する。**
過去のH5・checkpoint hashが記録されていない「不明」と混同しない。
過去hashの不明は限界として報告する。S17-5は次の来歴状態のまま続行する（2026-09-29管理判断）。`unknown`を一致確認済みと扱わず、coverageや整合性検査の通過を評価当時のコード・checkpointの同一性証明とは扱わない。
- 評価時点のgit revision、best・lastのcheckpoint SHA-256: **記録なし**（`unknown`）。追加探索を着手条件にしない。
- teacher H5の動画別SHA-256: **過去記録（teacher v7生成時のCSV）の存在は確認したが、封印対象のGT統計を含むため未照合**（`unknown`）。記録なしとは区別する。封印対象を解析してから捨てる方式は認めず、このCSVの本文は読まない。
- S5-15のframe可視化に記録された予測NPZのhash: **今回は照合に使わない**。将来参照できる記録として保持する。
記録があるのに一致しない場合は停止し、不明扱いへ落とさない。

### 5.4 mm指定時の欠落

**mm換算を指定した対象に必要な値が欠ける場合は実行全体を停止する。**
欠落動画の除外やpixel診断への自動切替をしない。
pixelモードは別に明示選択し、mm結果・T_FL判定を出さない。mm未確定でもpixelで物理長が保証されるわけではない。
元frame基準のx/y値、形式・完全一致キー・粒度・frame対応、`T_FL`は必要な実行前に確定する。
crop fallback resizeは保守的に入力評価不能とし、Stage4の修正へ無断で広げない。

## 7. 検証と報告の要件
